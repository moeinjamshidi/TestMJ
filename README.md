# Personal Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features a beautiful design with smooth animations, mobile-friendly navigation, and interactive elements.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works perfectly on all devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **Interactive Elements**: 
  - Smooth scrolling navigation
  - Parallax hero section
  - Animated statistics counters
  - Hover effects on project cards
  - Mobile-friendly hamburger menu
- **Sections**:
  - Hero section with introduction
  - About section with personal information and statistics
  - Skills section showcasing technical abilities
  - Projects portfolio with featured work
  - Contact form with validation
  - Footer with social links

## 🚀 Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Flexbox, Grid, and animations
- **JavaScript (ES6+)**: Interactive functionality and animations
- **Font Awesome**: Icons for skills and social links
- **Google Fonts**: Inter font family for typography

## 📁 File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript functionality
└── README.md          # Project documentation
```

## 🛠️ Setup & Installation

1. **Clone or download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content with your own information:
   - Edit personal details in `index.html`
   - Replace placeholder images with your own photos
   - Update social media links
   - Modify skills and projects sections
   - Customize color scheme in `styles.css` if desired

## 📱 Browser Compatibility

- Chrome (recommended)
- Firefox
- Safari
- Edge
- Mobile browsers (iOS Safari, Chrome Mobile)

## 🎨 Customization

### Colors
The website uses a modern color palette centered around indigo (`#4F46E5`). You can easily change the primary color by updating the CSS custom properties.

### Content
1. **Personal Information**: Update name, title, and description in the hero section
2. **About Section**: Replace the about text and statistics
3. **Skills**: Modify the skills categories and items
4. **Projects**: Replace with your own projects, including images and descriptions
5. **Contact**: Update contact information and social media links

### Images
- Replace the placeholder avatar image with your own photo
- Update project images with screenshots of your work
- All images should be optimized for web (WebP format recommended)
